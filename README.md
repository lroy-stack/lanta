# ExporLanta (Koh Lanta travel guide, prototype)

A bilingual travel-guide website for Koh Lanta, Thailand, generated with Lovable in May 2025 (page title: 'ExporLanta'). Content is static in the code; weather is simulated and there is no backend.

## What it does

- Pages: home, Discover (beaches, hidden gems, nature, culture), Experiences, Plan and Community.
- Planning tools: itinerary builder with drag and drop, seasonal guide, accommodation finder, transport guide and practical information.
- Community sections: photo gallery, travel journals, events, Q&A forum and local insights (static content).
- English and Thai interface with a language toggle saved in localStorage; interactive map and parallax headers.

## Built with

Vite, React 18, TypeScript, Tailwind CSS and shadcn/ui (Lovable's default stack), react-beautiful-dnd, Recharts.

## Run it locally

```bash
npm install
npm run dev      # dev server
npm run build    # production build (also copies public/.htaccess into dist/)
```

Status: archived prototype, not maintained.
